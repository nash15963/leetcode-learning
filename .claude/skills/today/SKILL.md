# 今日清單

## 步驟

1. 用 `date +%F` 取得今天日期。
2. 讀 `records/review-queue.md`：列出「下次日期 <= 今天」的題目，逾期的標出逾期天數。
3. 讀 `records/progress.md`：列出 🟡 進行中的題目。
4. 決定下一題新題：
   - 前置練習 001–017 還沒全部 ✅ → 下一題是 progress 裡第一個 ⬜ 的前置練習
   - 否則 → `records/roadmap.md` 第一個未打勾的 🟢 / 🔁（前面有未讀的 📖 也一起列出）
5. 統計進度：前置練習 x / 17、地圖 🟢 完成 y / 總數、待重做 z 題、已畢業 w 題。
6. 輸出簡短清單，建議今天的順序：**重做 → 進行中 → 新題**。例如：
   ```
   📅 2026-10-12
   🔁 重做（2）：004 vector-array-slice（第 2 輪）、013 two-sum（逾期 1 天）
   🟡 進行中：005 stl-algorithms
   🆕 下一題：006 hash-containers
   📊 前置 4/17 ・ 地圖 0/131 ・ 待重做 2 ・ 已畢業 0
   ```
7. 提醒重做方式：`make redo Q=NNN`（舊答案會備份到 `tmp/redo/`），寫完用 `/check NNN`。
