# 分級提示

參數：`$ARGUMENTS` = 題號，可以加上提示等級（1/2/3）。沒有題號時用 `records/progress.md` 最後一個 🟡 的題目。

## 步驟

1. 讀該題的 `question.md` 和使用者目前的 `main.cpp`（cpp-basics 練習題也要讀 `notes.md`），先判斷他的思路走到哪裡。
2. 決定等級：有指定就用指定的；沒指定時，這次對話還沒給過就從 L1 開始，給過就往上一級。
   - **L1 方向**：題目類型、該觀察的性質（例如「需要快速查詢某個值是否出現過」）
   - **L2 工具**：資料結構 / 演算法和對應的 C++ 容器或函式
   - **L3 虛擬碼**：步驟骨架（中文或虛擬碼），**不寫可以直接提交的 C++**
3. 如果使用者已經寫了一部分：針對他的程式給提示，例如指出哪一段邏輯有問題、給一個會讓它出錯的反例輸入。
4. **一次只給一級**，最後一句說明：「需要更多提示再輸入 `/hint NNN`」。
5. 在 `records/progress.md` 該題的備註欄記錄「用了 Lx 提示」（只保留最高等級）。
